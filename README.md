# Mahjong Play

用麻将牌拼英文单词的单文件网页游戏：摸一张、打一张，凑齐字母就能吃牌成词，手牌全成词即“胡”。

**在线玩**：https://winniezkatty-dotcom.github.io/mahjong-play/

## 玩法

- **对抗**：三人一桌，普通档随便打，困难档只认四六级/高考/课本里的正经词（语气词、缩写不算），倒计时 45 秒、求助 1 次
- **学习**：六个词包（小学低段、小学高段、初中、高中、大学成人、专四专八），先闪卡后拼牌，不设倒计时
- 打出一个词会有字母落桌和琴音，过关、开岛、开箱各有一段大场面

## 词库

- 13,878 个可打词，按考纲词 + 常用词筛出，剔除缩写与专业术语（`pem`、`es`、`bil` 这一类不会出现在牌里）
- 每个词带音标、词性与中文释义；释义经过词性对齐与去重整理
- 90 个偏难的词配了例句，出现在闪卡背面、拼词表演卡和求助提示里

## 文件

整个游戏就是一个 `index.html`，无依赖、无构建，双击即玩，也可以直接部署到任意静态托管。

- `index.html` — 最新版（Pages 使用这个）
- `Mahjong Play.html` — 同名副本（历史遗留）
