# Mahjong Play

用麻将牌拼英文单词的单文件网页游戏：摸一张、打一张，凑齐字母就能吃牌成词，手牌全成词即“胡”。

**在线玩**：https://winniezkatty-dotcom.github.io/mahjong-play/

## 玩法

- **对抗**：三人一桌，普通档随便打，困难档只认四六级/高考/课本里的正经词，倒计时 45 秒、求助 1 次
- **学习**：六个词包（小学低段、小学高段、初中、高中、大学成人、专四专八），先闪卡后拼牌，不设倒计时
- 打出一个词会有字母落桌和琴音，过关、开岛、开箱各有一段大场面

## 词库

- 4,138 个词，词表全局去重，没有重复条目
- **每个词都配例句**：英文原句 + 中文翻译，闪卡背面、拼牌表演卡、求助提示里都会出现
- 例句全部来自真人语料：Tatoeba 英汉句对（CC BY 2.0 FR）与项目内手写补充，没有机器生成的句子
- 想保住“每个词都有可靠例句”，词库从 1.3 万收敛到 4 千；没有例句的冷僻词暂时退出牌局
